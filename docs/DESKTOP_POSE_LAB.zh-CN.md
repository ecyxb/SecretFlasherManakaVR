# 桌面全身姿态实验室

`SecretFlasherManakaPoseLab.dll` 是独立的 BepInEx 6 IL2CPP 插件，用伪造的追踪输入验证游戏角色的全身骨骼控制。它不依赖 SteamVR，也不调用原 VR 插件。

## 已实现

- 可切换 6 / 8 / 10 / 11 点追踪，兼容原六点 JSON 输入。
- 头、左右手、骨盆、左右脚支持位置和旋转；膝盖和手肘的位置控制四肢弯曲方向；胸部独立参与躯干位置与旋转求解。
- 手臂和腿部使用解析双骨骼 IK；头部通过脊柱链 CCD 和可选骨盆补偿跟随。
- 双手握拳输入，控制人形骨架中的手指关节。拇指使用较小弯曲角度。
- 逐骨骼局部位置与旋转调节，可控制导出列表里的附加骨骼。
- 自动循环的模拟追踪动作，以及实时读取 JSON 的手动输入。
- 独立桌面预览、追踪点显示、骨骼分组选择、姿态保存和运行诊断。
- 启用时记录动画、RigBuilder、DynamicBone 和渲染状态；停用时恢复。预览用临时空闲渲染层隔离角色，并在关闭预览时恢复原图层和 Canvas 状态。

这是全身控制原型。尚未实现真实头显/手柄接入、自动步态、地面探测、关节生理限位、身体碰撞、眼动和动画混合。不能据此称为已经达到 VRChat 的完整 IK 品质。握拳轴根据当前手掌骨架推导，特殊手型可以使用逐骨骼偏移修正。

## 构建与安装

在仓库根目录运行：

```powershell
scripts\pose-lab.ps1 -GameRoot "E:\SecretFlasherManaka v1.1.3" -Action Build
scripts\pose-lab.ps1 -GameRoot "E:\SecretFlasherManaka v1.1.3" -Action Install
```

安装前关闭游戏。安装脚本会保存原配置，将原 VR DLL 暂存到 `BepInEx/config/ManakaPoseLab/backup`，关闭 VR 自动启动，然后安装实验插件。重复安装保留最初备份。

恢复原环境：关闭游戏后运行：

```powershell
scripts\pose-lab.ps1 -GameRoot "E:\SecretFlasherManaka v1.1.3" -Action Restore
```

恢复操作会还原原 VR DLL、配置及安装前的 Pose Lab DLL 状态，保留实验输入和诊断文件。

## 操作

进入实际游戏场景、等待角色完成加载后，在正常站姿下按 F6。启用瞬间的姿态作为校准基准；需要重新校准时，先关闭控制，待动画回到合适姿势后重新启用。

| 操作 | 按键/按钮 |
| --- | --- |
| 启用/释放控制 | F6 / ENABLE CONTROL / RELEASE CONTROL |
| 自动模拟动作 | F7 / DEMO |
| 独立预览 | F8 / Preview |
| 回到校准姿态，清除手动偏移 | F9 / Neutral |
| 显示/隐藏面板 | F10 |
| 保存手动输入 | Save input |

先选择追踪点数，再选择部位并调节滑块。未启用部位按钮置灰；膝肘仅显示位置滑块。拖动任一追踪或骨骼滑块会关闭自动演示。Left/Right grip 为 0–1 握拳程度。View yaw 旋转预览视角。

| 点数 | 参与求解的部位 |
| --- | --- |
| 6 | 头、双手、腰/胯、双脚 |
| 8 | 6 点加双膝 |
| 10 | 8 点加双肘 |
| 11 | 10 点加胸部 |

固定骨长、肩胯及手脚目标后，膝肘只能在可达的弯曲圆上取位置。输入的膝肘位置用于选择最近的弯曲方向，不保证任意目标都能精确重合；膝肘的旋转字段不参与求解。11 点模式优先保留给定的胯部位置和胸部旋转，胸部位置通过下段脊柱求解，头部位置通过胸部以上的关节求解。互相冲突的目标会留下位置误差，不拉长骨骼。

下方 DIRECT BONE CONTROL 用分组按钮筛选骨骼，再用左右按钮选择单根骨骼。位置偏移范围为 ±5 cm；它会叠加在 IK 结果上。F9 清除这些偏移。附加骨骼数量可能随衣装和其他插件变化。

为观察姿态，预览会暂时隐藏游戏的屏幕 Canvas；退出控制或关闭 Preview 会恢复。控制期间继续进行游戏交互可能被游戏逻辑再次修改模型，建议在静止场景测试。

## 伪造输入协议

运行目录：`<GameRoot>/BepInEx/config/ManakaPoseLab/`

| 文件 | 内容 |
| --- | --- |
| `input.json` | 每 0.5 秒检查修改时间，实时读取模拟输入 |
| `skeleton.json` | 启用控制时导出骨骼路径和校准姿态 |
| `status.json` | 每 2 秒输出实际骨骼姿态和追踪误差；停用时写入非活动状态 |

最小示例（未提供的字段使用默认值）：

```json
{
  "Enabled": true,
  "Demo": false,
  "Preview": true,
  "ShowTargets": true,
  "CameraYaw": 0,
  "Frame": {
    "TrackingPoints": 11,
    "PelvisFollowsHead": false,
    "Head": { "Yaw": 25 },
    "RightHand": { "Y": 0.18, "Z": 0.12 },
    "LeftKnee": { "X": -0.08, "Z": 0.12 },
    "RightKnee": { "X": 0.08, "Z": 0.12 },
    "LeftElbow": { "X": -0.12, "Z": -0.08 },
    "RightElbow": { "X": 0.12, "Z": -0.08 },
    "Chest": { "Yaw": 15 },
    "RightGrip": 0.75,
    "Bones": {}
  }
}
```

位置单位为米，旋转单位为度。追踪偏移使用以玩家朝向为准的坐标系：X 向右，Y 向上，Z 向前，零点是启用时各追踪部位的位置；不是绝对世界坐标。移动游戏角色时，追踪坐标系跟随角色根节点。

`TrackingPoints` 仅接受 6、8、10、11，省略时为 6。`PelvisFollowsHead=true` 允许骨盆在脊柱求解后补偿头部误差，适合模拟头手追踪。设为 false 时优先保留给定的髋部位置；11 点模式下始终保留髋部位置，不进行这项补偿；如果头和髋目标不能同时由现有骨长满足，头部会保留残差。手脚目标超出肢体可达范围时会被限制到可达位置，诊断记录的是实际末端与请求目标之间的误差。

`status.json` 的 `TrackingPoints` 表示已应用的配置；`Tracking` 提供每个部位的启用状态、约束类型、目标位置、实际位置与误差（米）。未启用部位的误差为 null。11 点时另有胸部位置和旋转误差。这些均为逐骨骼覆盖之前的 IK 结果。输入偏移先按部位限制幅度，状态中的目标是限制后的请求。

`Bones` 的键必须使用 `skeleton.json` 中的完整 `Path`，值支持 `X/Y/Z/Pitch/Yaw/Roll`，坐标为该骨骼的父空间。手动骨骼偏移最后应用，可以有意覆盖 IK 结果。状态中的 Head/Limb error 是 IK 阶段误差，不包含最后的逐骨骼覆盖。

输入先完整解析、验证后替换；非法 JSON 保留上一次输入并输出日志。外部脚本建议先写临时文件再原子替换 `input.json`。

## 实现和验证

- `TrackingLayout.cs`：四种追踪布局及部位顺序。
- `TrackingInput.cs`：`ITrackingInput`、模拟动作与输入模型。
- `PoseMath.cs`：不依赖 Unity 的双骨骼 IK 数学。
- `AvatarRig.cs`：角色识别、校准、躯干/四肢/手指求解及恢复。
- `PoseLab.cs`：面板、输入文件、预览、运行时状态。
- `Plugin.cs`：BepInEx 入口和游戏 LateUpdate 回调。

使用游戏自身的 LateUpdate 和独立预览相机 OnPreCull 重建姿态。每次都从校准数据开始，不会因同帧多相机调用累积偏移。不要给游戏所有相机批量添加注入回调：在本机游戏中，这条路径曾触发原生崩溃。

数学测试使用本机 .NET 10 SDK：

```powershell
dotnet run --project tests/PoseMath.Tests/PoseMath.Tests.csproj -c Release
```

本机已通过 677 项数学与追踪布局断言。在 v1.1.3 / Unity 2022.3.62f2 / BepInEx 6.0.0-be.755 中完成过：插件加载、骨架绑定、持续模拟运动、手动右手移动、15 度头骨旋转和释放控制的实测。右手移动请求为上移 18 cm、前移 12 cm；头骨局部旋转测得约 15.0000005 度。局部记录保存在仓库 `artifacts/pose-lab`，不进入 Git。


### 11 点扩展验证（0.2.0）

实机验证了 6 → 8 → 10 → 11 → 6 切换，以及未启用部位输入不影响骨架。两组膝盖目标使膝部移动约 14.52 cm，两组手肘目标使肘部移动约 26.73 cm；对应固定手脚末端位移均低于 0.001 mm。胸部请求旋转 20°，实际局部旋转变化约 20°；另一组胸部位置输入使胸部移动约 3.04 cm。11 点零偏移的头部和胸部位置残差均低于 0.001 mm。这些是固定输入下的数值验证，不代表动态输入或任意人体比例也有同样精度。

非法点数 7 被拒绝并保留上一有效姿态；释放控制恢复成功。详细本地记录在 `artifacts/pose-lab/eleven-point`。真实动捕设备、追踪器到人体关节的安装偏移标定和追踪丢失处理尚未接入；当前自动演示与 JSON 都是伪造输入。
